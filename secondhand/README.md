# ReWear: сайт секонд-хенда (демо)

Статический сайт без сборки в стиле Apple. Данные и фото — примеры
(фото с Unsplash, подгружаются по ссылке).

## Что есть

- **Каталог** отборных вещей: поиск, категории, состояние, сортировка, бейджи
  «Новинка», «Забронировано», «Подлинность ✓», быстрый просмотр.
- **Корзина** (сохраняется в браузере): самовывоз или курьер, проверка имени и
  телефона, заказ уходит готовым сообщением в WhatsApp.
- **Зал на вес**: скидка по дням недели, сегодняшний день подсвечивается сам.
- **Сдать вещи**: калькулятор выплаты за вещи на комиссию, заявка в WhatsApp.
- **Опт для бизнеса**: мешки сортированного товара, счётчик, запрос счёта в WhatsApp.
- **Контакты**: адрес, часы, телефон, Instagram, 2ГИС.

## Как поменять данные

Всё в [`js/data.js`](js/data.js): название, адрес, телефон (`STORE.phone` — только
цифры, для WhatsApp), часы, доставка, товары `PRODUCTS`, цены зала `HALL`,
ставки комиссии `CONSIGN`, оптовые лоты `WHOLESALE`. Вёрстку трогать не нужно.

Чтобы снять вещь с продажи — поставьте `status: 'reserved'` или удалите строку.
Фото товара — id снимка Unsplash в `photo`; для своих фото замените функцию `IMG`.

## Запуск

```bash
python -m http.server 5173
```

Откройте http://localhost:5173/secondhand/.

## Структура

- `index.html` — разметка
- `css/styles.css` — основа, навигация, герой; `css/catalog.css` — каталог и окно товара;
  `css/sections.css` — зал, приём вещей, опт, контакты, корзина
- `js/data.js` — данные; `js/utils.js` — помощники; `js/cart.js` — корзина;
  `js/catalog.js` — каталог; `js/forms.js` — калькулятор и опт; `js/main.js` — запуск
