# TopSpin: сайт клуба настольного тенниса (бета)

Статический сайт без сборки: клуб и 3 стола, бар, аренда стола по времени,
абонементы, тренеры и группы, турниры и чемпионы.

## Версии

- `/` — бета 1: тёмный дизайн, все разделы (клуб, бар, аренда, абонементы, турниры, чемпионы).
- `/v2/` — бета 2 в стиле Apple: столы, онлайн-бронирование по шагам, абонементы.
  Данные бета 2 лежат в [`v2/js/data.js`](v2/js/data.js).

## Как поменять данные

Все тексты, цены, тренеры, расписание, турниры и контакты лежат в
[`js/data.js`](js/data.js). Вёрстку трогать не нужно.

> Сейчас там примеры. Занятость столов в аренде генерируется для демонстрации
> и не связана с реальными бронями.

## Локальный запуск

```bash
python -m http.server 5173
```

Откройте http://localhost:5173.

## Структура

- `index.html`: разметка страницы
- `css/styles.css`: стили
- `js/data.js`: данные клуба
- `js/booking.js`: аренда столов
- `js/sections.js`: остальные разделы
- `js/main.js`: запуск страницы
